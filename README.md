# 我的弹跳玩偶 · MineDoll

> 我的世界皮肤玩偶动画生成器

把 Minecraft 皮肤变成会跟着音乐弹跳的 3D 玩偶，并导出成 MP4 或 GIF。

纯网页工具，打开即用：不需要安装、不需要登录，皮肤和导出文件都只在本地浏览器处理。

- 支持 64×64、64×32 旧版、高清皮肤、Steve / Alex 纤细手臂、镂空皮肤
- 玩偶模式：头放大、身体缩小、可坐下，按 120 BPM 压缩弹跳
- 默认旋律按《朋友的酒》编排，可导入自己的音频替换
- 多模型：一圈玩偶绕着你选中的那个转，切换时像旋转木马一样转一格
- 导出 MP4（1080P / 4K，60fps）或 GIF（480×480 正方形，适合当表情包）
- 可以将整个工具打包成一个 HTML 上传到 B 站 Toy

## 打开方式

**本地 / 自己服务器**

直接双击 `index.html` 即可。想用完整功能（尤其是 MP4 导出）建议起一个本地服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

**B 站 Toy**

上传 `toy/index.html` 即可，它是一个自包含的单文件页面。

## 使用说明

### 1. 导入皮肤

点击工具栏左侧的「导入皮肤」，选择 PNG；也可以直接把图片拖进页面，支持一次拖入多张。

支持的格式：

| 类型 | 说明 |
| --- | --- |
| 64×64 | 现代标准皮肤，含外层（帽子 / 外套） |
| 64×32 | 旧版皮肤，会自动补齐左臂、左腿 |
| 高清倍率 | 128×128 等，按比例放大 |
| 纤细 | Alex 3px 手臂，自动识别，也可手动指定 |
| 镂空 | 大面积透明皮肤，可指定填充色 |

### 2. 管理模型

导入后模型会出现在工具栏的「模型」里，点缩略图即可切换。多模型模式下，点画面也会切到下一个模型。

「+ 默认」可以把内置示例皮肤加回场景。

### 3. 单个 / 多个

- **多个**：选中的模型放大在中间，其他模型面朝前绕圈
- **单个**：只显示当前模型；打开「旋转」后会按八拍一圈（约 4 秒）匀速转

### 4. 玩偶与动作

- **标准 / 玩偶**：玩偶模式会放大头部、缩小身体
- **坐下**：玩偶模式下可用，腿会向前放平
- **弹跳**：按 120 BPM 压缩回弹。开启弹跳后，单击画面可以让节拍重新从第一拍开始

### 5. 视角

- 拖拽：旋转视角
- 滚轮 / 双指捏合：缩放
- 手机：单指拖动旋转，双指捏合缩放
- 「重置视角」：回到默认机位

### 6. 背景

「背景 → 选择图片」可以放一张自定义背景图，导出时也会带上；「清除」恢复默认。

### 7. 更多设置

点「更多设置」展开：

| 选项 | 作用 |
| --- | --- |
| 外层图层 | 显示 / 隐藏皮肤的帽子、外套、袖子等第二层 |
| 手臂模型 | 自动识别 / 经典 4px / 纤细 3px |
| 镂空皮肤填充颜色 | 透明像素的填充色，仅镂空皮肤可调 |
| 画面比例 | 自动跟随屏幕、横屏 16:9、竖屏 9:16 |

### 8. 背景音乐

- 「♪ 音乐」：播放 / 暂停
- 「导入音频」：选择本地音频文件作为背景音乐
- 导入后按钮会变成「更换音频」，旁边出现「默认旋律」可切回内置旋律

内置旋律由代码实时合成，不包含任何音频文件；导入音乐的版权由使用者自行负责。

### 9. 导出

点「导出」：

1. 选择背景：白色 / 镂空（透明）/ 背景图
2. 选择画质：1080P 60 / 4K 60
3. 导出 MP4 或 GIF

说明：

- MP4 与预览画面完全一致（横屏 1920×1080、竖屏 1080×1920，4K 同比例翻倍），白色背景方便直接发群
- GIF 固定 480×480 正方形，方便做表情包
- 多模型时，MP4 会依次放大每个模型；GIF 导出当前阵列
- 导出过程有进度条，期间请不要关闭页面

## 常见问题

**打不开 3D 预览？**
浏览器需要支持 WebGL。请更新浏览器，或在设置里开启硬件加速。

**导出的不是 MP4，而是 WebM？**
当前环境不支持 WebCodecs（常见于 `file://` 直接打开或旧浏览器）。用本地服务器打开，或更新浏览器即可。

**视频时长显示不正常？**
已经内置时长修补；如果播放器仍显示异常，换一个播放器（如 PotPlayer、VLC）确认。

**「镂空皮肤填充颜色」是灰的？**
只有检测到镂空皮肤时才会启用；普通不透明皮肤不需要填充。

**手机上工具栏挤？**
窄屏会自动换行；建议横屏或使用电脑导出视频。
